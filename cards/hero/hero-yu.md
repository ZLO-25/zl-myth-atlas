## 故事

### 父親的失敗

洪水淹沒了天下。《尚書·堯典》記載，堯問四方諸侯之長：「湯湯洪水方割，蕩蕩懷山襄陵，浩浩滔天。下民其咨，有能俾乂？」意思是：浩浩蕩蕩的大水，包圍山頭、淹上丘陵，人民都在嘆氣，有誰能治好它？大家都推薦鯀。[s6]

《山海經》說，禹的父親鯀偷了天帝的「息壤」（一種會自己長大的土）去堵洪水，沒有等天帝同意，天帝就派祝融在羽山的郊外殺了鯀。[s2][s4] 原文是「鯀復生禹。帝乃命禹卒布土以定九州」：鯀的肚子裡又生出了禹，天帝於是命令禹把土鋪好，安定九州。[s2] 鯀的詳細故事見[[hero-gun|鯀]]。

《史記》的版本比較像歷史：堯任用鯀治水，九年沒有成功；舜巡視時發現治水無功，處死了鯀，改派鯀的兒子禹接手。[s1] 舜任命禹時只說了一句：「女平水土，維是勉之。」意思是：你去整治水土，好好努力。[s1]

### 堵不如疏

禹記取父親失敗的教訓，不再只是築堤堵水，而是開通河道，把水一路導進大海。[s1] 《尚書·禹貢》開頭就說：「禹敷土，隨山刊木，奠高山大川。」意思是禹把土地劃分整治，沿著山勢砍樹做記號，確定高山大河的位置。[s8] 〈益稷〉記下禹自己的話：「予乘四載，隨山刊木……予決九川，距四海，濬畎澮距川。」他說自己乘著四種交通工具跋涉，疏通九條大河直通四海，又把田間的小溝挖深，接進河裡。[s7]

他在外辛苦奔波，經過自己家門都沒有進去。[s1][s3] 《史記》說，禹因為父親治水失敗被殺，「勞身焦思」，在外十三年，「過家門不敢入」；他吃穿簡單，卻對鬼神很虔誠，自己住的房子矮小，卻把錢花在水溝上。[s1] 《史記》接著照錄九州的土質、賦稅與貢品，那些內容和《尚書·禹貢》相合。[s1][s8]

```
鯀：  洪水 → 築堤堵住 → 水越積越高 → 潰堤 → 失敗
禹：  洪水 → 開挖河道 → 水往低處流 → 入海 → 成功
```

### 塗山氏與啟

〈益稷〉裡，禹對舜說：「娶于塗山，辛壬癸甲。啟呱呱而泣，予弗子，惟荒度土功。」意思是：娶了塗山氏，只過了辛、壬、癸、甲四天就出門；兒子啟呱呱哭著，我也顧不上當他的父親，一心只想著治理土地。[s7] 《楚辭·天問》則問：「焉得彼嵞山女，而通之於台桑？」意思是：他怎麼會在台桑那個地方，跟塗山氏的女子成婚？[s9]

《吳越春秋》把這段寫得更有故事：禹三十歲還沒結婚，走到塗山，有一隻長著九條尾巴的白狐走到他面前。禹說：「白者，吾之服也。其九尾者，王之證也。」白色是我穿的顏色，九條尾巴是當王的證明。於是他娶了塗山氏的女兒，叫女嬌，新婚四天就離開；十個月後女嬌生下啟，啟一生下來就沒見過父親，從早到晚呱呱啼哭。[s10] 這隻狐狸後來的變化，見[[beast-ninetail-fox|九尾狐]]。

### 從「讓賢」到「傳子」

舜把王位讓給了治水有功的禹。[s1] 禹死前把天下交給了賢臣益，但諸侯都去朝見禹的兒子啟，益就讓位，啟成了天子。[s1] 從此王位由父親傳給兒子，古書把這當作夏朝的開始，也是神話慢慢變成歷史的轉折點。[s1][s5]

## 各書怎麼說

```
書              禹在外多久        其他說法
孟子（戰國）     八年，三過其門     禹薦益於天，七年禹崩
史記（西漢）     十三年，過門不敢入  東巡到會稽而崩
吳越春秋（東漢） 七年，過門不入     塗山九尾白狐、宛委山得書
```

《孟子》說：「禹八年於外，三過其門而不入。」[s3] 《史記》說十三年。[s1] 《吳越春秋》說七年：「聞樂不聽，過門不入，冠掛不顧，履遺不躡」，意思是聽到音樂也不聽，帽子被樹勾住也不回頭看，鞋子掉了也不去撿。[s10] 三本書的年數不同。[s3][s1][s10]

禹死的地方，《史記》說他東巡到會稽就去世了。[s1] 《吳越春秋》則說，啟派人每年春秋兩季到越地祭禹，在南山上蓋了宗廟。[s10]

《竹書紀年》（今本）寫成：「禹薦益於天，七年，禹崩，三年喪畢，天下歸啟。」[s11]

另一個傳說見《國語·魯語下》：孔子說，從前禹把眾神召集到會稽山，防風氏晚到，禹就把他殺了，他的骨節大到能裝滿一輛車。[s12] 

## 後來怎麼變

最早的記載裡，禹是「布土定九州」的神話英雄。[s2][s8] 戰國的《孟子》說他疏通九河，把水注入海，「三過其門而不入」。[s3] 到了漢代的《史記》，禹有了完整的家譜：他是黃帝的玄孫、顓頊的孫子，名叫文命，鯀則是被舜依法處死。[s1] 東漢的《吳越春秋》又加進塗山九尾白狐、宛委山取得金簡玉字之書等傳奇，並把禹和越地的會稽連在一起。[s10]

《楚辭·天問》則一連串發問：為什麼鯀治不好，禹卻能繼承事業、「纂就前緒，遂成考功」？[s9] 這說明在戰國時代，鯀、禹父子的故事已經有了許多讓人想不通的地方。[s9]
