## 故事

### 父親的失敗

洪水淹沒了天下。《山海經》說，禹的父親鯀偷了天帝的「息壤」（一種會自己長大的土）去堵洪水，沒有等天帝同意，天帝就派祝融在羽山的郊外殺了鯀。[s2][s4] 鯀的肚子裡生出了禹，天帝於是命令禹把土鋪好，安定九州。[s2]

《史記》的版本比較像歷史：堯任用鯀治水，九年沒有成功；舜巡視時發現治水無功，處死了鯀，改派鯀的兒子禹接手。[s1]

### 堵不如疏

禹記取父親失敗的教訓，不再只是築堤堵水，而是開通河道，把水一路導進大海。[s1] 他在外辛苦奔波，經過自己家門都沒有進去。[s1][s3]

```
鯀：  洪水 → 築堤堵住 → 水越積越高 → 潰堤 → 失敗
禹：  洪水 → 開挖河道 → 水往低處流 → 入海 → 成功
```

### 從「讓賢」到「傳子」

舜把王位讓給了治水有功的禹。[s1] 禹死前把天下交給了賢臣益，但諸侯都去朝見禹的兒子啟，益就讓位，啟成了天子。[s1] 從此王位由父親傳給兒子，古書把這當作夏朝的開始，也是神話慢慢變成歷史的轉折點。[s1][s5]
