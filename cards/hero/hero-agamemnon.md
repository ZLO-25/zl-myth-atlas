## 故事

### 被詛咒的家族

阿波羅多洛斯記下的家族史從坦塔洛斯開始：他在[[place-underworld|冥界]]被罰站在水池裡，水碰到下巴卻一喝就乾，頭頂的果樹被風吹向雲端；有人說他是因為向人洩露眾神的祕密，又想把神的食物分給同伴。[s1] 他的兒子珀羅普斯曾在眾神的宴席上被宰殺、煮過，復活後更俊美。[s1] 珀羅普斯贏得希波達米亞時，車伕米爾提洛斯被他扔進海裡，臨死詛咒了珀羅普斯的家。[s1]

珀羅普斯的兩個兒子阿特柔斯與堤厄斯忒斯爭王位。堤厄斯忒斯誘惑阿特柔斯的妻子，拿走金羊；阿特柔斯後來騙他來和解，殺了他的三個兒子，煮給他吃。[s1] 堤厄斯忒斯照神諭與自己的女兒生下艾吉斯托斯，艾吉斯托斯長大後殺了阿特柔斯。[s1]

```
坦塔洛斯（冥界受罰）
  │
珀羅普斯（米爾提洛斯詛咒）
  ├─ 阿特柔斯
  │    ├─ 阿伽門農
  │    └─ 墨涅拉奧斯
  └─ 堤厄斯忒斯
       └─ 艾吉斯托斯
```

### 伊菲革涅亞

阿伽門農娶了廷達瑞俄斯的女兒克呂泰涅斯特拉（[[hero-helen|海倫]]的姊妹），生下俄瑞斯忒斯與三個女兒。[s1] 希臘艦隊在奧利斯被風困住，先知卡爾卡斯說，必須獻上阿伽門農最美的女兒給阿提密斯；阿伽門農騙妻子，說要把女兒嫁給[[hero-achilles|阿基里斯]]。[s1] 艾斯奇勒斯寫他在兩難中屈服，將領們一心想打仗，對少女的哀求毫不在乎，他叫人把她像小山羊一樣舉到祭壇上。[s2] 阿波羅多洛斯則說，阿提密斯在最後一刻把她帶走，換成一隻鹿，讓她去陶里人那裡當祭司。[s1]

### 回家

艾斯奇勒斯的《阿伽門農》裡，克呂泰涅斯特拉承認殺夫，說這是她早就盤算好的舊帳，又質問長老們：為什麼不放逐殺女兒的人。[s2] 《奧德賽》裡，阿伽門農的亡魂向[[hero-odysseus|奧德修斯]]說，是艾吉斯托斯請他赴宴，在宴席上殺他，他的同伴被殺，卡珊德拉也被克呂泰涅斯特拉殺死。[s4]

### 俄瑞斯忒斯與雅典的審判

厄勒克特拉把弟弟俄瑞斯忒斯送去外地長大；成年後他到[[place-delphi|德爾菲]]求問，[[god-apollo|阿波羅]]允許他報仇，他殺了母親與艾吉斯托斯，隨後被復仇女神追趕，逃到雅典受審。[s1] 艾斯奇勒斯《和善女神》裡，法庭上他承認殺了母親，說是照阿波羅的神諭；票數相等，[[god-athena|雅典娜]]說她投給俄瑞斯忒斯，他被判無罪。[s3] 雅典娜說服復仇女神留在雅典，接受新的榮譽；Theoi 說，「和善女神」這個名字據說是從俄瑞斯忒斯獲判無罪之後才開始用的。[s3][s6]

## 各書怎麼說

```
阿伽門農怎麼死的？
奧德賽    宴席上被殺，像宰牛
艾斯奇勒斯  浴盆裡，被長袍罩住
阿波羅多洛斯 穿無領無袖的衣服時被殺
```

三種說法的人手與場景都不同，各書並列，沒有哪一種是定論。[s1][s2][s4]

## 後來怎麼變

最早的《奧德賽》把罪責放在艾吉斯托斯身上；艾斯奇勒斯讓克呂泰涅斯特拉站到台前，替女兒辯護，並用審判結束家族的血仇。[s2][s3][s4]

## 今天在哪裡遇到

邁錫尼出土的金面具被稱為「阿伽門農面具」，因為施里曼認為它屬於荷馬筆下的英雄。[s5] 但古希臘網站說，後來的斷代把它放在西元前 16 世紀，比阿伽門農的時代早了約三百年；它的真偽也曾被質疑。[s5]
