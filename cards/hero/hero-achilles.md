## 故事

### 兩種命運

阿基里斯的母親是海中女神忒提斯，她知道兒子的命運有兩條路：留在家鄉，可以平安長壽，卻默默無名；去特洛伊作戰，會年輕戰死，但名聲永遠不滅。[s3] 阿基里斯選了後者。

### 憤怒

《伊里亞德》第一句就是「女神啊，請歌唱阿基里斯的憤怒」。[s2] 戰爭第十年，統帥阿伽門農搶走了阿基里斯的女俘，阿基里斯覺得受辱，從此拒絕出戰。希臘軍隊節節敗退。

他最親密的戰友帕特羅克洛斯看不下去，穿上阿基里斯的盔甲出戰，卻被特洛伊王子赫克托耳殺死。悲痛的阿基里斯重回戰場，穿上[[god-hephaestus|赫菲斯托斯]]連夜打造的新盔甲與神盾。[s2]

```
阿伽門農搶走女俘 → 阿基里斯罷戰 → 希臘軍敗退
      → 帕特羅克洛斯代他出戰而死 → 阿基里斯暴怒復出
      → 殺死赫克托耳、拖屍示眾 → 老國王普里阿摩斯夜裡來求屍
```

他殺死赫克托耳，把屍體綁在戰車後面拖行。[s4] 一天夜裡，赫克托耳年邁的父親、特洛伊國王普里阿摩斯獨自來到希臘營帳，跪下親吻殺子仇人的手，求他歸還兒子的屍體。阿基里斯想起自己的父親，兩個敵人相對痛哭，他答應了。[s5] 史詩就在赫克托耳的葬禮中結束，沒有寫到阿基里斯的死。

### 腳踝的一箭

後來的作者補上了結局：阿基里斯在特洛伊城門前，被特洛伊王子帕里斯和[[god-apollo|阿波羅]]射中腳踝而死。[s6] 至於「全身刀槍不入、只有腳跟是弱點」，那是更晚才出現的說法（見下方「說法不一」）。
