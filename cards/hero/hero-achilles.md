## 故事

### 兩種命運

阿基里斯的母親是海中女神忒提斯，她知道兒子的命運有兩條路：留在家鄉，可以平安長壽，卻默默無名；去特洛伊作戰，會年輕戰死，但名聲永遠不滅。[s3] 阿基里斯選了後者。

### 童年與出征

阿波羅多洛斯說，珀琉斯把嬰兒交給[[monster-centaurs|半人馬]]凱隆，凱隆用獅子與野豬的內臟、熊的骨髓餵養他，並取名阿基里斯，意思是「嘴唇沒碰過乳房」，在那之前他叫利基戎。[s14] 阿基里斯九歲時，先知卡爾卡斯宣布：沒有他，特洛伊攻不下來。忒提斯知道兒子去了就會死，便讓他穿女裝，把他當成少女托給呂科墨得斯國王；他在宮裡與國王的女兒德伊達彌亞生下兒子皮洛斯，也就是後來的涅俄普托勒摩斯。[s14] [[hero-odysseus|奧德修斯]]找到宮裡，用一陣號角聲識破了他，他就這樣去了特洛伊。[s14]

### 憤怒

《伊利亞德》第一句就是「女神啊，請歌唱阿基里斯的憤怒」。[s2] 統帥[[hero-agamemnon|阿伽門農]]搶走了阿基里斯的女俘，阿基里斯覺得受辱，從此拒絕出戰。[s2] 希臘軍隊節節敗退。

他最親密的戰友帕特羅克洛斯看不下去，穿上阿基里斯的盔甲出戰，卻被特洛伊王子[[hero-hector|赫克托]]殺死。悲痛的阿基里斯重回戰場，穿上[[god-hephaestus|赫菲斯托斯]]連夜打造的新盔甲與神盾。[s11]

```
阿伽門農搶走女俘 → 阿基里斯罷戰 → 希臘軍敗退
      → 帕特羅克洛斯代他出戰而死 → 阿基里斯暴怒復出
      → 殺死赫克托、拖屍示眾 → 老國王普里阿摩斯夜裡來求屍
```

他殺死赫克托，把屍體綁在戰車後面拖行。[s4] 一天夜裡，赫克托年邁的父親、特洛伊國王普里阿摩斯在[[god-hermes|荷米斯]]引路下潛入希臘軍營，獨自走進阿基里斯的營帳，跪下親吻殺子仇人的手，求他歸還兒子的屍體。阿基里斯想起自己的父親，兩個敵人相對痛哭，他答應了。[s5] 史詩就在赫克托的葬禮中結束，沒有寫到阿基里斯的死。

荷馬寫得更細：贖屍之前，阿基里斯每天黎明把赫克托綁在戰車後，繞帕特羅克洛斯的墓拖三圈；阿波羅替遺體蓋上金色神盾，不讓它受損。[s17] 在《奧德賽》第 11 卷，奧德修斯在[[place-underworld|冥界]]遇見阿基里斯的亡魂，對他說，你生前如神，死後也統治亡者，不必悲傷。阿基里斯回答：寧可活在人間替沒有田產的窮人當雇工，也不要當所有亡者的王；接著他急著打聽兒子與父親珀琉斯的消息。[s15] 這與他當年選擇「短命而榮耀」形成對照。[s3][s15]

### 腳踝的一箭

後來的作者補上了結局：阿基里斯在特洛伊城門前，被特洛伊王子帕里斯和[[god-apollo|阿波羅]]射中腳踝而死。[s8] 至於「全身刀槍不入、只有腳跟是弱點」，那是更晚才出現的說法（見下方「說法不一」）。

### 死前與死後

阿波羅多洛斯的摘要說，亞馬遜女王彭特西勒亞殺了許多人，最後被阿基里斯殺死；他在她死後愛上了她，還殺了嘲笑他的忒耳西忒斯。[s16] 曙光女神之子門農帶著衣索比亞人來援，殺了許多希臘人，包括安提洛科斯，後來被阿基里斯殺死；阿基里斯追擊特洛伊人時，在斯開亞城門被帕里斯與阿波羅射中腳踝。[s16][s8] 赫克托臨死前在《伊利亞德》也預言過，帕里斯與阿波羅會在斯開亞城門殺死他。[s4]

屍體周圍打了起來，埃阿斯殺了格勞科斯，背著遺體穿過箭雨，奧德修斯在後面擋住敵人。[s16] 希臘人把他與帕特羅克洛斯的骨頭混在一起，埋在白島，舉行競技；他的盔甲後來成了埃阿斯與奧德修斯爭奪的獎品。[s16] 特洛伊陷落後，希臘人把波呂克塞娜殺在他的墳上。[s16] 有人說他死後在福人島與[[hero-medea|美狄亞]]同住。[s16]

## 各書怎麼說

```
阿基里斯怎麼死、什麼弱點？
伊利亞德   赫克托預言他死在斯開亞
           城門；沒寫死亡；前臂曾流血
阿波羅多洛斯 腳踝中箭；母親用火煉他
斯塔提烏斯 母親把他浸入冥河
```

荷馬的史詩裡沒有寫到阿基里斯之死，只有預言；[s4][s10] 摘要補上腳踝中箭；[s8] 刀槍不入與冥河的細節要到一世紀的斯塔提烏斯才出現。[s9]
