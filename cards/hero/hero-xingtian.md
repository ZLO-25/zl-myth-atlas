## 故事

《山海經·海外西經》在介紹一個個「海外之國」的段落中，插進了一條沒有國名的記載：「刑天與帝爭神，帝斷其首，葬之常羊之山，乃以乳為目，以臍為口，操干戚以舞。」[s1] 白話是：刑天和天帝爭奪神的地位，天帝砍下他的頭，把頭埋在常羊山；他卻拿兩個乳頭當眼睛、肚臍當嘴巴，手持盾牌（干）和大斧（戚）跳起舞來。[s1] 這個「舞」字，也可以理解成揮舞兵器作戰。[s1]

這條記載夾在「奇肱之國」和「女祭、女戚」之間，前後都是一臂三目的人、居兩水之間的巫女這類奇人異事，刑天是其中之一。[s1] 版本上，有的寫「刑天」，有的寫「形天」，有的在「爭神」前多一個「至此」，意思是到了這裡才爭神。[s1]

《山海經》只寫「帝」，沒有說是哪一位，也沒有說刑天為什麼爭、爭的是什麼神位，更沒有說他的名字從何而來。[s1] 常見的「刑天對黃帝」，是後人把「帝」補成具體人物的講法；原文本身並沒有這樣寫。[s1][s3]

### 山海經裡的另一個無頭人

〈大荒西經〉另有一段：「有人無首，操戈盾立，名曰夏耕之尸。」接著說，商朝的開國君主成湯在章山討伐夏桀，打勝了，在夏耕面前把他砍了頭；夏耕雖然站了起來，卻沒有頭，不知道往哪裡跑，只好逃到巫山。[s4] 這個無頭、拿著武器站起來的人，和刑天很像，但《山海經》沒有說兩者有關。[s4][s1]

```
海外西經          大荒西經
刑天              夏耕之尸
和「帝」爭神       成湯伐夏桀
被砍頭、葬常羊山    被砍頭、站起來
乳為目、臍為口      逃到巫山
操干戚以舞         操戈盾而立
```

### 從怪物變成英雄

陶淵明讀《山海經》，寫了十三首詩。第十首的前四句是：「精衛銜微木，將以填滄海；刑天舞干戚，猛志故常在。」意思是精衛嘴裡銜著小木頭，要填平大海；刑天揮舞著盾和斧，那股剛猛的志氣永遠都在。[s2] 詩的後半說：「同物既無慮，化去不復悔。」意思是，牠們和萬物同是自然之物，沒有什麼好憂慮的，死了變成別的東西，也不後悔。[s2] 一句詩，讓一個無頭的怪物，變成了「打不倒」的象徵。[s2]

## 各書怎麼說

《淮南子·墜形訓》介紹地形與各方異人時，說：「西方有形殘之屍。」[s5] 有人認為「形殘之屍」指的就是刑天，但這是後來的對應，《淮南子》本身沒有寫出名字。[s5][s3]

```
書                    朝代    刑天
山海經·海外西經        先秦至漢  與帝爭神，被砍頭，以乳為目、臍為口
山海經·大荒西經        先秦至漢  沒有刑天，但有同樣無頭操戈盾的夏耕之尸
淮南子·墜形訓          西漢     「西方有形殘之屍」，可能指刑天
陶淵明〈讀山海經〉其十   東晉     猛志常在，死而不悔
```

## 後來怎麼變

《山海經》裡的刑天只是一個沒有頭的人，沒有說他是好是壞。[s1] 陶淵明把他和精衛並列，讚美他們不屈服的志氣；現在常說的「刑天舞干戚」，就是從這句詩來的，用來形容受挫仍不肯認輸。[s2] 同一首詩裡的精衛，見[[hero-jingwei|精衛]]。[s2]
