## 故事

### 兩種梅杜莎

最早的赫西俄德只說：戈爾貢三姊妹住在世界盡頭的海洋彼岸，其中梅杜莎是凡身，另外兩位斯忒諾與歐律阿勒不死不老。海神[[god-poseidon|波賽頓]]曾和她同床；柏修斯砍下她的頭時，大英雄克律薩俄耳與飛馬佩加索斯從她頸中跳了出來。[s1] 赫西俄德沒有說她曾經是美女，只說她「遭遇了悲慘的命運」。[s1]

大約七百年後，羅馬詩人奧維德讓柏修斯親口講了另一個版本：有人問為什麼三姊妹裡只有梅杜莎頭髮是蛇。柏修斯回答，她原本是許多人追求的美女，最美的是她的頭髮。海神在[[god-athena|雅典娜]]的神殿裡侵犯了她，雅典娜轉過臉、用盾遮住眼睛，事後卻把梅杜莎的頭髮變成蛇；女神如今把這些蛇帶在胸前，嚇唬敵人。[s2]

```
古希臘的梅杜莎：天生的怪物、驅邪的鬼臉
羅馬的梅杜莎：  被侵害、又被懲罰的少女
現代的梅杜莎：  常被重新解讀為受害者的象徵
```

阿波羅多洛斯還記下另一種說法：有人說，柏修斯是為了雅典娜才砍她的頭，因為梅杜莎想在美貌上和女神比。[s3]

### 柏修斯怎麼砍下她的頭

[[hero-perseus|柏修斯]]奉國王波呂得克忒斯之命去取梅杜莎的頭。阿波羅多洛斯說，他在荷米斯與雅典娜的指引下，先去找葛賴埃三姊妹：她們三人共用一隻眼睛和一顆牙，柏修斯趁她們傳遞時搶走，逼她們說出仙女的所在，向仙女借到有翅的涼鞋、袋子（kibisis）和隱形帽，又從荷米斯手中拿到一把鐮刀。[s3]

他飛到海洋邊，趁三姊妹睡著動手。阿波羅多洛斯寫戈爾貢頭髮纏著龍鱗，有野豬般的獠牙、青銅的手和黃金的翅膀，看她一眼的人都會變成石頭；所以柏修斯背對著看，只看銅盾上的倒影，在雅典娜導引下揮鐮刀砍下頭，飛馬與克律薩俄耳隨即出生，兩者都是波賽頓的孩子。[s3] 另兩位姊妹醒來追趕，卻看不見戴著隱形帽的他。[s3]

### 死後的武器

柏修斯用她的頭石化了好幾個敵人：在衣索比亞擋下想搶回安朵美達的菲紐斯一黨，又用它對付波呂得克忒斯和他的朋友，最後把頭獻給雅典娜，女神把它裝在自己的神盾上。[s3] 古希臘人也常把她的頭像放在盾牌和獻給神的建築上。[s4]

## 各書怎麼說

```
          赫西俄德   奧維德    阿波羅多洛斯
天生怪物    是        否        是（獠牙、龍鱗）
受罰變蛇    無        有        另說：與女神比美
生出飛馬    是        是        是
```

荷馬史詩裡的戈爾貢只是恐怖的頭：《伊利亞德》寫雅典娜披上神盾，盾上有「戈爾貢的可怕頭顱」；阿伽門農的盾牌中央也畫著戈爾貢，兩側是恐怖與驚慌。[s5] 《奧德賽》第十一卷，奧德修斯在冥界門口害怕冥后會從冥府放出戈爾貢的頭，嚇得趕快回船。[s6]

## 後來怎麼變

赫西俄德說佩加索斯飛上天，住在宙斯家裡替他帶雷電。[s1] Theoi 條目收了這些說法，並指出佩加索斯是從她被砍斷的脖子生出來的。[s7] 奧維德把梅杜莎寫成先被侵害、又被懲罰的少女，和赫西俄德筆下天生的怪物很不一樣。[s2]
