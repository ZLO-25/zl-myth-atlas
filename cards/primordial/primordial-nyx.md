## 故事

### 從卡俄斯來的夜

赫西俄德寫創世：先有卡俄斯，然後大地、塔爾塔羅斯與厄洛斯；接著「從卡俄斯生出厄瑞玻斯與黑色的夜」，夜與厄瑞玻斯結合，生下以太（明亮的空氣）與白晝。[s1] 所以在這個說法裡，白天是從夜晚生出來的。

赫西俄德還寫到世界盡頭有夜神的家：大地與天空交界處，她的家被黑雲包住。夜與白晝在青銅門檻相遇、互相問候，一個進屋，另一個出門；家裡從不同時容納她們兩個。留在屋裡的夜神，手臂抱著睡眠，睡眠是死亡的兄弟。[s7]

### 沒有父親的孩子

赫西俄德特別說，夜神「不曾與任何人同睡」，獨自生下一大群孩子。這份名單裡有：厄運、死亡、睡眠、夢的一族、批評、痛苦、命運三女神、報應女神涅墨西斯、欺騙、老年與紛爭。[s1]

```
夜神（獨自生下）
 ├─ 死亡、睡眠、夢    ← 人的終點與夜晚
 ├─ 命運三女神        ← 見 god-fates
 ├─ 涅墨西斯（報應）
 ├─ 欺騙、老年
 └─ 厄里斯（紛爭）
```

這張名單全是人類不愛、卻逃不掉的東西。[s1]

### 連宙斯也要讓她三分

《伊利亞德》第 14 卷，天后希拉請睡神讓宙斯睡著。睡神拒絕，因為上一次他讓宙斯睡著，宙斯醒來大怒，要把他從天上扔進海裡，是夜神救了他。他說夜神「制服眾神與人類」，宙斯因為敬畏，不敢做出讓她不高興的事。[s2]

## 各書怎麼說

```
夜神的出身
 赫西俄德   卡俄斯的女兒
 奧菲斯教   厄洛斯（法涅斯）的女兒
 阿里斯托芬 夜神自己下蛋生出厄洛斯
```

三種說法都把她放在創世的最開頭，只是排序不同。[s1][s4][s6] 艾斯奇勒斯的《和善女神》裡，復仇女神自稱「夜神永恆的孩子」，還說命運女神是她們同母的姊妹，這和《神譜》裡復仇女神出自烏拉諾斯之血的說法並不一致。[s3]

## 後來怎麼變

後來的詩人不再把她當創世力量，而只是夜晚的化身：有時是有翅膀的女神，有時駕著車穿過天空，身披黑衣、有星星跟著。[s6] 羅馬詩人叫她 Nox。維吉爾寫埃涅阿斯為她獻上黑毛羔羊，說她是復仇女神之母。[s8] 羅馬的詩人把她和巫術連在一起，例如奧維德筆下的女巫美狄亞會呼喊「夜，神祕儀式之母」。[s6]
