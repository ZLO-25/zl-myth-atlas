## 故事

《山海經·海外東經》說：「下有湯谷。湯谷上有扶桑，十日所浴……居水中，有大木，九日居下枝，一日居上枝。」[s1] 白話是：湯谷是十個太陽洗澡的地方，谷上的扶桑生在水中，是一棵大樹；九個太陽待在下面的樹枝，一個在上面的樹枝。[s1]

```
        ☀            ← 上枝：今天輪到的太陽
       ╱│╲
   ☀☀☀ │ ☀☀☀       ← 下枝：其餘九個太陽休息
     ☀☀ │ ☀
  ～～～湯谷～～～   ← 太陽洗澡的地方
```

屈原在〈離騷〉裡寫「總余轡乎扶桑」，把馬韁繫在扶桑樹上；王逸注說，那是「結我車轡於扶桑，以留日行」，想把太陽的行程留住，以求長壽。[s2] 這棵樹，就是[[story-houyi-suns|后羿射日]]故事裡十個太陽的家。[s3]

## 各書怎麼說

- 《山海經·海外東經》：扶桑在湯谷上、「居水中」。[s1]
- 《山海經·大荒東經》：「有山名曰孽搖頵羝，上有扶木，柱三百里，其葉如芥。有谷曰溫源谷。湯谷上有扶木。一日方至，一日方出，皆載于烏。」[s4] 這裡的扶木長在山上，高三百里，葉子像芥菜，太陽由烏鴉載著，一個回來、一個出發。[s4] 書中一處說樹在水中、一處說樹在山上，兩者並不一致。[s1][s4]
- 《楚辭·離騷》：「總余轡乎扶桑」，王逸注：「扶桑，日所拂木也」。[s2]
- 《淮南子·天文訓》（西漢）：太陽的一天從「日出于暘谷，浴于咸池，拂于扶桑」開始，「登于扶桑，爰始將行」才算出發；因此扶桑是太陽升空之前的站點。[s5]
- 王充《論衡·說日篇》（東漢）：他引儒者說法「日旦出扶桑，暮入細柳」，再用冬夏日出方位不同來反駁，說太陽並不是從扶桑出、入細柳。[s6]
- 《神異經·東荒經》（題為西漢東方朔撰）：「扶桑山有玉雞，玉雞鳴則金雞鳴，金雞鳴則石雞鳴，石雞鳴則天下之雞悉鳴，潮水應之矣。」山上有玉雞帶頭啼叫，天下的雞跟著叫，海潮也隨之漲落。[s8]
- 《述異記》（南朝梁，任昉）：「磅磄山去扶桑五萬里，日所不及，其地甚寒」，把扶桑當成一個距離的基準點。[s9]

## 後來怎麼變

從《山海經》的大樹，到《淮南子》裡一天行程的一站，再到王充用日出方位質疑它是否存在，扶桑逐漸從神話地點變成方位上的「東」。[s1][s5][s6] 後來《明史·日本傳》記載日本王良懷對明朝使者說：「吾國雖處扶桑東，未嘗不慕中國。」[s7] 這裡的「扶桑」已是一個方位或地名，不再是神樹。[s7]
