## 故事

《山海經·海外東經》說，湯谷上有扶桑樹，是十個太陽洗澡的地方；水中有一棵大樹，九個太陽住在下面的樹枝，一個太陽住在上面的樹枝。[s1]

```
        ☀            ← 上枝：今天輪到的太陽
       ╱│╲
   ☀☀☀ │ ☀☀☀       ← 下枝：其餘九個太陽休息
     ☀☀ │ ☀
  ～～～湯谷～～～   ← 太陽洗澡的地方
```

屈原在〈離騷〉裡寫「總余轡乎扶桑」，把馬韁繫在扶桑樹上，想像自己跟著太陽一起出發。[s2] 這棵樹，就是[[story-houyi-suns|后羿射日]]故事裡十個太陽的家。[s3]
