1. This file contains 40 image prompts, grouped into 8 stories. Generate ONE image per prompt, in the order listed.
2. Use each "PROMPT" block exactly as written. Every image: realistic cinematic digital painting, landscape 4:3 (1600x1200), no text, letters, calligraphy or seals in the image.
3. Keep characters consistent within a story: the same person must have the same face, hair, age and clothing in every frame. Before the first frame of each story, first create a character reference sheet from the character lines, then reuse it.
4. After each image, state its FILE NAME (for example img-ai-buzhou-1) so the user can save it with that name.
5. Work one story at a time. When a story is finished, say "Story finished: <story name>" and wait for the user before starting the next story.
