# 第 1 期計畫（定稿）

完整的計畫討論稿在 Claude Doc：<https://claude.ai/artifact/Pe9EoEwcFZCX12GE4Dyd96>。ZL 在 2026-11-02 選定 AI 插畫畫風 C（現代平塗），並說「繼續」，計畫照此執行。這份檔案只記錄最後實際採用的版本，方便以後對照。

## 目標一句話

做一個給台灣成年人看的希臘＋羅馬神話網站：圖多、故事好讀，而且每一個事實都能點開來源查證。

```
原典（荷馬、赫西俄德、奧維德…） ─┐
現代來源（Theoi、WHE、UNESCO…） ─┼─► 卡片（Markdown＋YAML） ─► validate 檢查 ─► 網站
Wikimedia Commons 真實作品圖   ─┘                                   │
AI 插畫（ZL 生圖，標「AI 插畫」）──────────────────────────────────────┘
```

## 範圍

| 項目 | 計畫 | 實際 |
|---|---|---|
| 卡片 | 約 40 張 | 45 張（原始神 3、泰坦 4、泰坦之戰 1、神 15、英雄 8、故事 10、怪物 2、地點 2） |
| 分格故事 | 至少 8 個 | 10 個，每個 6–8 格 |
| 今日影子 | 至少 60 條 | 69 條 |
| 真實作品圖 | 每位神至少 2 張 | 96 張；卡厄斯、烏拉諾斯例外（見報告） |
| 頁面 | 卡片、族譜、年代軸、地圖、冥界圖、對照表、今日影子、搜尋 | 全部完成 |

## 技術

Vite＋React＋TypeScript；地圖 Leaflet；族譜 d3-zoom；搜尋 Fuse.js；部署 GitHub Pages。卡片與資料檔在 `cards/`、`data/`，`scripts/validate.ts` 是守門員：資料有錯，網站就不會部署。
