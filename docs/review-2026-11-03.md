# 第 1 期檢視報告：神話正確性、教學設計、介面（2026-11-03）

以神話研究者、教學者、UI/UX 三個角度把 45 張卡、69 條今日影子與整個網站走過一遍，能直接改的都改了（這份報告對應的 PR）。缺圖的部分先不管。

## 一句話結論

內容很紮實（7 位獨立查核者的成果看得出來），真正的問題在「怎麼帶讀者走」：
網站有很多好東西，但沒有告訴新手先看什麼、看完接著看什麼；另外有一個會讓正文亂掉的程式 bug。

```
            以前                              現在
讀者進站 ─► 6 張精選卡 ─► ？                  讀者進站 ─► 怎麼用（3 步）─► 新手路線 8 張（照故事順序）
                                                            │
卡片頁：三句話 → 名畫 ×3 → 分格 → 正文 …      卡片頁：三句話 → 本頁內容 → 分格 → 正文 → 名畫 → … → 接著讀 3 張
         （手機上要滑過三張大圖才看到故事）             （先聽故事，再看畫家抓哪一刻）
```

## 一、神話正確性（只有小修）

逐張核對了原典段落與行數、家族關係、希羅差異、今日影子的 diff。沒有發現錯誤的情節或錯的出處，只改了 5 處：

| 卡片 | 問題 | 改法 |
|---|---|---|
| 希拉 | 三句話寫「見『今日神話』」，網站上的欄位叫「今日影子」 | 改成「今日影子」 |
| 赫斯提亞 | 主題標籤是「家族詛咒」，和她完全無關 | 改成「羅馬借用希臘」「王權更替」 |
| 宙斯 | 一句話「長大後吐出哥哥姊姊」讀起來像宙斯自己吐 | 改成「逼老爸吐出哥哥姊姊、再推翻他」 |
| 黑帝斯 | 「迪士尼的狗布魯托用他的羅馬名」略過一層：狗是跟著 1930 年新發現的冥王星取名 | 補上「跟著冥王星取名」 |
| 地圖頁冥界圖 | 寫「極樂世界」，冥界卡片寫「極樂淨土」 | 統一成「極樂淨土（Elysium）」 |

檢查時特別看過、確認沒問題的幾個常見陷阱（可以拿去教）：

- 阿基里斯「刀槍不入、只有腳跟」：卡片正確指出荷馬沒這樣寫，是公元一世紀斯塔提烏斯才有的。
- 潘朵拉的「盒子」其實是大陶罐（pithos）：正確，連伊拉斯謨的誤譯都有交代。
- 赫斯提亞「讓位給酒神」：卡片明寫查無古代出處，這是對的，很多入門書都講錯。
- 波賽頓是宙斯的哥哥還是弟弟：赫西俄德與荷馬不同，卡片兩說並列。
- 六月 June 是否來自朱諾：標「說法未證實」，奧維德自己就列了三種說法。

## 二、教學設計

### 問題 1（bug）：正文裡的 ASCII 示意圖變成一行亂碼

荷米斯、阿基里斯、柏修斯、奧菲斯、伊底帕斯、冥界、特洛伊戰爭、羅慕路斯等 10 張卡的正文用 ``` 畫了流程圖，
但網站的極簡 Markdown 不認得 ```，整段被壓成一行、連反引號都露出來。

```
原本：  "```清晨  出生中午  在洞口撿到一隻烏龜……```"   ← 一行、看不懂
現在：  ┌──────────────────────────┐
        │ 清晨  出生                │
        │ 中午  撿到烏龜 → 發明七弦琴 │   ← 畫成方塊，手機上可左右捲
        │ 傍晚  偷走阿波羅的五十頭牛  │
        └──────────────────────────┘
```

修法：`src/components/bits.tsx` 的 `Markdown` 先把 ``` 區塊切出來，畫成 `<pre class="ascii">`。加了一條自動測試防止再壞。

### 問題 2：新手不知道從哪開始、接著看什麼

- 首頁加「怎麼用這個網站」三步驟：認得他 → 聽故事 → 認出今天的影子。
- 首頁加「新手路線」8 張卡，照故事順序（蓋亞 → 克羅諾斯 → 宙斯 → 普羅米修斯 → 波瑟芬妮 → 特洛伊戰爭 → 奧德賽 → 埃涅阿斯），每張一句「為什麼要讀」。讀完就有整部神話的骨架：創世 → 王權更替 → 神與人 → 季節 → 戰爭 → 返鄉 → 羅馬。
- 卡片頁底部加「接著讀」3 張：先用前因後果的卡，不夠再補同年代的卡。
- 這些是第 1 期範圍內的輕量引導；第 2 期的「學習單元、故事線」會更完整，不衝突。

### 問題 3：卡片頁的閱讀順序

- 原本「名畫」放在「分格故事」與「正文」之前，手機上要滑過三張大圖才看到故事。
- 改成：三句話 → 一句話 → 本頁內容（可跳轉）→ 掌管／怎麼認 → 分格故事 → 正文 → 名畫 → 希羅 → 家族 → 前因後果 → 說法不一 → 今日影子 → 來源 → 接著讀。
- 名畫區加一行引導：「讀完故事再看圖：『看這張圖』會告訴你畫家抓的是哪一刻。」
- 「說法不一」加一行：「神話沒有標準版本，不同時代的作者常講得不一樣。」這是整個網站最重要的教學訊息，值得每次提醒。

### 問題 4：小處

- 「一句話記住他」對地點／怪物／故事卡改成「這個地方」「牠」「這個故事」。
- 「神話裡有歷史影子」的卡（特洛伊、米諾陶洛斯、奧林帕斯山、羅慕路斯）原本只有一個小標籤，證據藏在資料裡沒顯示；現在開頭就把 evidence 和來源亮出來。
- 別張卡寫的前因後果（例如希拉卡寫「她促成特洛伊戰爭」）原本在特洛伊戰爭卡看不到；現在會顯示並註明「寫在希拉的卡片」。
- 今日影子清單裡「說法未證實」的條目在卡片頁也標出來。

## 三、介面（UI/UX）

| 改什麼 | 為什麼 |
|---|---|
| 卡片頁「本頁內容」跳轉列 | 一張卡 10 個段落，手機要滑很久 |
| 年代標籤可以跳到年代頁的那一格，並短暫框起來 | 原本只跳到年代頁頂端 |
| 族譜：配偶超過 4 位改成兩排 | 宙斯有 10 位配偶，排一排時整張圖縮到字看不清 |
| 卡片列表：類型按鈕顯示數量、加「有希臘版本／有羅馬版本」篩選、顯示共幾張 | 讓人知道這一類有多少、羅馬獨有的雅努斯在哪 |
| 手機不顯示滑過浮出的小卡 | 觸控沒有「滑過」，原本點了會直接跳頁，小卡閃一下反而干擾 |
| 搜尋框按 Esc 關閉結果 | 鍵盤使用者的基本預期 |
| 首頁精選區改名「最多人認識的 6 張」 | 原本叫「從這裡開始」，但沒有順序，和新手路線的角色混淆 |
| `<meta name="theme-color">` | 手機瀏覽器網址列跟著愛琴海藍 |

## 四、還沒做、建議下一步

1. 第 2 期計畫（學習單元、故事線）可以直接承接「新手路線」的骨架，把 8 張擴成單元。
2. 搜尋結果可以加上下鍵選取；地圖頁的地點清單可以依卡片篩選。這些都小，等第 2 期一起。
3. SVG 插畫試作見 `docs/svg-samples/`，等 ZL 決定要不要用。

## 五、補：總覽頁（ZL 2026-11-03 要求）
