Myth Atlas Norse mythology illustration job sheet — 15 images

【給 Grok 的說明 / Instructions for Grok】
1. This file contains 15 image prompts, grouped into 3 stories. Generate ONE image per prompt, in the order listed.
2. Use each "PROMPT" block exactly as written. Every image: realistic cinematic digital painting, landscape 4:3 (1600x1200), no text, letters or written runes in the image.
3. Viking-age Scandinavian look only: wool and linen clothing, longhouses, longships. NO horned helmets, NO Marvel-style or superhero costumes, NO modern fantasy armour.
4. Keep characters consistent within a story: the same person must have the same face, hair, age and clothing in every frame. Before the first frame of each story, first create a character reference sheet from the character lines, then reuse it.
5. After each image, state its FILE NAME (for example img-ai-ragnarok-1) so the user can save it with that name.
6. Work one story at a time. When a story is finished, say "Story finished: <story name>" and wait for the user before starting the next story.
