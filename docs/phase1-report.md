網站：<https://zlo-25.github.io/zl-myth-atlas/>　｜　計畫：[phase1-plan.md](phase1-plan.md)　｜　查核原始報告：[source-check/](source-check/)

## 一、這一期在解決什麼問題

網路上的神話介紹常有兩個毛病：一是「大家都這樣說」，卻找不到出處；二是把後人加的情節（例如阿基里斯腳跟浸冥河）當成原典。這一期的目標，是做出一個**每一句話都能點開來源**的神話網站，而且讓讀者看得出「原典怎麼說、後人怎麼改」。

```
一般神話網站                         眾神星圖
────────────                         ────────────
故事 ──► 讀者                         故事 ──[s1][s2]──► 讀者
（出處不明）                                │
                                           ▼
                                     點開：荷馬《伊里亞德》21.166
                                           World History Encyclopedia…
```

## 五、獨立查核：查出什麼、怎麼修

7 位沒有參與寫作的查核者，各負責一批卡片或資料檔，**逐一打開來源網頁**，比對卡片上每一句話。嚴重度分六級：

```
WRONG        寫錯了（來源說的跟卡片相反）           19 處 ─► 全部改正
UNSUPPORTED  來源沒有提到這件事                     126 處 ─► 補正確出處，或刪掉那句話
LINE         行號範圍沒涵蓋那段文字                  19 處 ─► 改行號
LINK         網址打不開或連到錯的頁面                13 處 ─► 換成正確網址
UNREACHABLE  查核工具被網站擋住，打不開              見下方
STYLE        用字容易誤會                            82 處 ─► 大多已改
```

### 查出的典型錯誤（拿來教人很好用）

| 卡片 | 原本寫 | 原典其實說 | 教訓 |
|---|---|---|---|
| 普羅米修斯 | 宙斯被騙，選了包著骨頭的脂肪 | 赫西俄德說宙斯**看穿了**詭計，故意選的 | 「大家都這樣說」的版本，常和原典相反 |
| 阿基里斯 | 引 WHE 說「腳跟」最早出自斯塔提烏斯 | WHE 沒寫；改引斯塔提烏斯原文和《伊里亞德》21.166 | 結論對，出處也要對 |
| 奧德修斯 | 裝瘋時把驢和牛綁著犁田撒鹽 | 阿波羅多洛斯只寫帕拉墨得斯搶嬰兒拔劍；犁田是更晚的許癸努斯 | 不同古代作者的版本不能混著引 |
| 阿特拉斯 | 海克力斯「在肩膀上墊軟墊」 | 原文是「在頭上墊軟墊」 | 細節也要照原文 |
| 雅努斯 | 「一切開始都屬於我」 | 奧維德寫的是「我守著門檻，你們要經過我才能到達眾神」 | 漂亮的句子最容易是編的 |
| 波瑟芬妮 | 吃了「幾顆」石榴籽 | 頌歌是一顆，奧維德才是七顆 | 數字要回去數 |
| 星巴克 | 官方說靈感來自十六世紀北歐木刻 | 官網現在只說「古老航海書裡的插圖」 | 企業網頁會改，要以現在的內容為準 |
| 鈦元素 | 取名「泰坦」是形容金屬強韌 | 化學家只是仿照鈾用神話命名 | 「聽起來合理」不等於有出處 |

### 其他修正

- 「認出這位神」的欄位：原本常引用一個根本沒談藝術的神話百科頁；改成直接引用本站收錄作品的 Commons 作品頁。
- 4 個 World History Encyclopedia 連結其實是「搜尋結果頁」，已換成真正的文章。
- 史特拉波《地理學》連結的頁碼不存在，已改成正確分頁；「喀耳刻之島」改引 5.3.6。
- 音樂劇 Hadestown 原本譯成《冥王星城》（冥王星是行星，不對），台灣查不到通行譯名，改寫《Hadestown》（黑帝斯之城）。
- 網站部署流程改回「資料有錯就不部署」。

### 還沒解決、需要知道的事

- **查核工具打不開、但人用瀏覽器打得開的網站**：Perseus（李維）、Wikimedia Commons 作品頁、美國心理學會辭典、Adweek。查核者改用鏡像站或 Commons API 資料比對，內容一致。
- **流行文化條目**（Nike、喬伊斯《尤利西斯》、迪士尼《大力士》、波西傑克森、刺客教條、聖鬥士星矢）的「作品內容」只靠維基百科（標「輔助」）。神話那一半有原典。之後可換成官方或評論來源。
- **「蠍子殺死獵戶」**的說法本站找不到可靠的古代出處，已在條目裡直接寫明。

## 七、ZL 要做的事：生 63 張 AI 插畫

```
1. 打開 data/ai-art-prompts.yaml
      │  每張圖有 id、所屬卡片、場景描述；開頭的 style 是畫風 C 的共同設定
      ▼
2. 用你的生圖工具，把「style ＋ 出場角色設定 ＋ scene」貼進去生圖
      │  橫式 4:3，建議 1600×1200
      ▼
3. 存成 WebP：public/images/ai/<卡片 id>/<圖 id>.webp
      │  例：public/images/ai/story-pandora/img-ai-pandora-1.webp
      ▼
4. 推上 GitHub（或丟給我）
      │  網站下次部署會自動把佔位圖換成真圖，「AI 插畫」標籤自動加上
      ▼
5. 我逐張比對角色設定與原典，不符合就改提示詞請你重生
```

畫面規則（不放文字、暴力只用構圖暗示、不露骨）寫在 [art-style.md](art-style.md)。
