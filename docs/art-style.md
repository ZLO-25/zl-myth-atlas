# 眾神星圖 AI 插畫規範（寫實數位繪畫）

ZL 在 2026-11-02 先選了畫風 C（現代平塗），2026-11-08 看過 Grok 的第一張試作後，改成**寫實數位繪畫**。這份文件是生圖時的「角色設定集」，目的是讓同一個角色在不同張圖裡長得一樣。

## 一、寫實畫風怎麼和真實古物分開

```
真實古物（陶瓶、雕像、壁畫） ──► 照片，標「古代作品」或「後世名作」，附館藏與授權
AI 插畫（本站自己做的）       ──► 寫實數位繪畫，左下角固定標「AI 插畫」
                                 提示詞明寫「不是照片、不是陶瓶畫」，不冒充古物
```

## 二、色調

溫暖的地中海色調：赤陶橘、愛琴海藍、橄欖綠、大理石白，金色點綴。自然光，不用霓虹或奇幻光效。

## 三、畫面規則

1. 寫實數位繪畫：自然光、可信的人體與材質；不是照片、不是動漫、不是仿陶瓶的紅黑繪。
2. 構圖像圖像小說的一格：主角清楚、背景簡化。
3. 畫面裡不放任何文字；「AI 插畫」標籤由網站自動加上，不要畫進圖裡。
4. 暴力用構圖暗示（舉起的武器、倒下的剪影、遠景），不畫傷口特寫與血；性與裸露只用含蓄的構圖，不畫露骨內容。
5. 尺寸：橫式 4:3，建議 1600×1200，存成 WebP，放在 `public/images/ai/<卡片 id>/<圖 id>.webp`。放進去之後，網站下次建置就會自動把佔位圖換成真圖。

## 四、角色設定（依原典與傳統圖像）

角色外觀寫在 `data/ai-art-prompts.yaml` 的 `characters` 區塊，每張圖的提示詞會自動把出場角色的設定接上去。設定的依據：

|---|---|---|
| 宙斯 | 灰黑捲髮與大鬍子、壯年、藍色披風、手握金色雷電 | 奧特里科利的宙斯頭像、阿特米西翁青銅像 |
| 雅典娜 | 高冠頭盔、長矛、胸前有梅杜莎頭的神盾、貓頭鷹 | 瓦瓦奇恩的雅典娜（帕德嫩神像縮小版） |
| 荷米斯 | 年輕無鬍、有翅膀的寬邊帽與涼鞋、雙蛇杖 | 詹波隆那〈墨丘利〉、柏林畫家雙耳瓶 |
| 阿芙蘿黛蒂 | 金髮、白色薄袍、鴿子 | 波提且利〈維納斯的誕生〉 |
| 黑帝斯 | 和宙斯相似但更陰沉的大鬍子、深色袍、權杖、三頭犬 | 洛克里陶板、韋爾吉納壁畫 |

## 五、生圖與檢查流程

```
Claude：寫提示詞（data/ai-art-prompts.yaml）＋放佔位圖，網站先能跑
   │
   ▼
ZL：用自己的生圖工具產圖 → 存到 public/images/ai/<卡片>/<圖 id>.webp
   │
   ▼
Claude：逐張比對角色設定與原典 ──► 不符合：改提示詞，請 ZL 重生
                                  └► 符合：在 YAML 填上實際使用的工具名稱
```
